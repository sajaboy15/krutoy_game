## 1. Biome def

Registry: `G.Biomes = {defs, register(def), get(id)}`. `get` of an unknown id returns `Object.assign({}, defs._fallback, {id})` (room-generator level, purple void, plays "zindan").

### Fields (who reads them, when)

| Field | Used by | Meaning |
|---|---|---|
| `id`, `name`, `subtitle` | UI card/map (`w(biome)` ≈ L32266) | title texts; fallback `G.STORY.biomes[id]` |
| `music` | `loadStage` → `Audio.music(r.music \|\| r.id)` (boss: `r.music \|\| 'boss'`) | Tracks: `title bukhara zindan steppe bazaar alatoo afrasiab registan chaikhana boss_kempir boss_barys boss_aidahar death victory arena`. **Unknown id → "arena"** |
| `enemyBiome` | `populate`: `Enemies.list(enemyBiome \|\| id)` | pools: `zindan, steppe, bazaar, alatoo, afrasiab, registan` (empty pool → `dummy`) |
| `ambient`, `shade`, `deepShade` | `LevelGen.bakeLightBase` | **the real lighting**: air in open = ambient; air under any solid (overhang/ceiling) → shade; solid tiles → deepShade by depth. `G.Light.ambient` is overwritten by lightBase, so setting it at runtime does nothing |
| `sunDir` `[dx,dy]` | `bakeShadows` | drop-shadow direction on back chunks (3/6 px probe) |
| `wind` | player scarf, flames, smoke, cloth | number (−1..2) |
| `dust`, `rock` | `FX.dust` on landing / `FX.debris` on impacts | color arrays |
| `bloom` | display (default .55) | bloom strength |
| `gen` | `loadStage`: `gen.open ? LevelGen.open : LevelGen.generate` | see §2 |
| `arena` | boss entries: `LevelGen.arena(biome, {seed, ...biome.arena, ...bossDef.arena})` | `{w,h,outdoor,platforms,wallH}` |
| `tiles` `{solid,plat,back,spike,ladder}` | `bake` | `(ctx, x, y, info)`; `info`: `tx,ty,x,y,t,up,down,left,right` (true = open side), `upT..` neighbour types, `ul,ur,dl,dr`, `depth` (0–8), `back`, `h,h2` hashes, `level`. Missing → `G.TileDefaults` |
| `backMask(level,tx,ty,cur)` | all generators | → bool: draw back wall here (false shows sky/parallax) |
| `lore` | `showLore` | strings for lore stones |
| `decorate(level, rng)` | `loadStage`, before bake | push into `level.decos` (below) |
| `bakeChunk(backCtx, frontCtx, x, y, 256, level)` | `bake`, per chunk | extra painting; forces all chunks non-null |
| `buildBackground(level)` → layers | after bake | parallax list (below) |
| `drawSky(ctx,cam,t,level)` | every frame, first, screen space | must fill the screen (no clear) |
| `lights(Light,cam,t,level)` | every frame | add lights (`Light.add`) |
| `fogBehind(ctx,cam,t,level)` | after sky+parallax, before world composite | screen space; tint/haze the background only |
| `drawForeground(ctx,cam,t,level)` | after world+FX | screen space overlay |
| `post(ctx,cam,t,level)` | after foreground, before vignette/glow | grading via `globalCompositeOperation` (`soft-light`, `lighter`, …) |
| `update(world,t)`, `ambientFx(world,cam,t)` | every tick (60/s, may run 0–4× per frame) | logic / spawn ambient particles |
| `build` | (bukhara only, empty, never called) | — |
| `sunReturn`, `eclipseCrack`, `AMB`, `SHADE` | registan_square only | state driven by the aidahar boss / `G.SunReturn`; `update` crossfades two baked lightBases (`_lb0/_lb1/_lbMix`) — reuse this pattern for animated time of day |
| `_sky`, `_fg`, `_haze` | caches some biomes keep **on their own closure def** | variants copying methods share them |

Decos (`level.decos`): static `{static:true, layer:'back'|'front', bx,by,bw,bh, draw(ctx)}` are baked into chunks (cheap); dynamic `{x,y,r, layer:'back'|'mid'|'front', draw(ctx,t,d), fx(ctx,t,d), update(d,t), light:{r,color,a,flicker,dx,dy}}` run per frame (`back` behind entities, `mid` between front tiles and entities, `front` after lighting = unlit; `fx` after lighting; `light` auto-added when on screen). `PixKit.addStatic(level, canvas, x, y, layer)` makes a static deco.

Parallax layers: `{canvas, fx, fy, y, x, drift, alpha, repeat:false, extend:false}` (x = −cam.x·fx + t·drift, tiles horizontally, bottom row stretched down unless `extend:false`) or `{draw(ctx,cam,t)}`.

### Frame order (`main.unmin.js` L6845)
drawSky → parallax → world canvas: back chunks, `back` decos, entities layer<0, front chunks, `mid` decos, entities, player, FX(world) → dynDeco lights + `biome.lights` → `Light.render` (ambient fill, lightBase, additive lights) → world ×= light (multiply) → `fogBehind` → world composited → `fx` of decos, entity drawFx, FX(glow), `front` decos, damage texts → `drawForeground` → `post` → vignette → `Glow.render` → display + bloom(`biome.bloom`) → HUD.

## 2. LevelGen

`LevelGen` (L3158+): `generate(biome, seed)` (room grid), `open(biome, seed)` (side-scroller strip; **every shipping level uses it**), `arena(biome, opts)`, `chaikhana(biome)`, `bake(level, biome)` (256-px chunks back/front), `bakeShadows`, `bakeLightBase` (per-tile light → 4× blurred canvas), `drawChunks`, `drawParallax`. `G.Level`: `w,h,tiles,back,zone,depth, get/set/fill/in/idx, solidPx, computeSpots()` (→ `spots.floor/ceil/wallL/wallR`), `computeDepth()`, `objects, spawns, decos, spawn, exit`. Tiles `G.T = {AIR:0, SOLID:1, PLAT:2, SPIKE:3, LADDER:4}`, `G.TS = 16`.

**`open` params** (defaults): `width 230` (= level length in tiles, the only length knob), `height 60`, `base 16` (ground thickness), `amp 6` (upper limit of terrain), `enemies [1,2]` (per 10 tiles of each run × run density), `platforms .5` (floating beams), `spikes false`, `segments` weights `plain hills cliff chasm building tower bridge colonnade terrace islands arena`. Output extras: `structures` (kinds building/tower/bridge/pier/colonnade/terrace/island/chasm/stone/beam/arena with x0,x1,floorY,roofY,…), `segments`, `groundRow`, `structOf(tx,ty)`, `isOpen=openTop=true`. Chests/urns come from buildings/towers/cliffs (scale with width); **scrolls 2, lore 1, urns 3, food 1 are fixed** at fractions .33/.71/.52/…; elites 1–2.

**`generate` params**: `cols 6, rows 3, rw 30, rh 18` (size = cols·rw × rows·rh), `vertChance .5`, `sideRooms .45` (side rooms hold chest/altar), `loops .3`, `enemies [2,4]` per path room, `outdoor`/`skyRows`, `spikes` (pits), `hang` (stalactites), `features {raise,pit,plats,pillar,deck,low,none}`. Enclosed → whole level lit by `shade`.

**Traversal** (bot, god mode, `test/runbot.js`): pure running 27–40 s per shipping level (3360–3712 px; run speed 2.05 px/frame); real play with 10–20 enemies ≈ 2–4 min.

**Recipe 1.5–2× longer** (`long_levels.js`, tested): raise only `gen.width` (210→380 gave 34 spawns vs 20, 16 segments, 2 chests, load 0.4 s), keep `height`/`base` (bukhara/steppe backgrounds anchor on the *original* def's `gen.base`), and add the fixed objects with `K.addObjectsAt(L, [[.15,'scroll'],[.9,'scroll'],[.78,'lore']])` in `postGen`. Generation fills to `width-30` then flat run, so any width ≥ ~80 works; memory ~2× chunks (≈100 canvases 256²).

## 3. PLAN

`G.PLAN` = array of `{type:'level',biome}` / `{type:'rest'}` / `{type:'boss',biome,boss}` / `{type:'victory'}`. `G.stageOf(i)` = count of level+boss entries before i. `loadStage(i)`: `run.planIndex=i; run.stage=G.stageOf(i)`; missing entry or victory → victory state; `diff.hpMul = 1+.42·stage`, `diff.dmgMul = 1+.2·stage`; level seed `run.seed+7919·i` (+31·(deaths+1) on retry); rest → `chaikhana`, `level.nextBiome = PLAN.slice(i+1).find(e=>e.biome).biome` (aksakal story `STORY.aksakal[nextBiome] || .steppe`); boss → arena, boss spawns when player x > 9 tiles. `exitStage` → `planIndex+1`.
`run.stage` also drives: loot tier `floor(.8·stage)`, item `minStage`, gold `×(1+.25·stage)`, chest gold, shop prices, boss loot, some DoT dps.

Depends on stage count: stage card `"ЗЕМЛЯ "+["I".."VII"][n-1]` → **"ЗЕМЛЯ undefined" from the 8th level**; boss music after defeat = victory only for `aidahar`; yodgor `victoryIndex()` uses findIndex (ok), its save stores `planIndex` (old saves break if PLAN changes); yodgor tables keyed by biome id simply skip new ids.

**Recipe (tested, `plan30.js` + `test/plan30.js`, all 30 entries load, `?stage=25` works):**
```js
K.setPlan([...30 entries...]);              // mutates G.PLAN in place, warns on unknown biome/boss
K.difficulty = K.linearDifficulty(10);      // G.stageOf override: last fight = stage 10 (orig peak 8; raw 20 would be 9.4× HP)
// optional per entry: {type:'level', biome:'dev_gut', label:'ГЛУБИНА I', title:'…', sub:'…'}
```
BiomeKit wraps `UI.onStageStart` → roman numerals to any n (`K.levelLabel` overridable); note numbering counts *all* level entries, custom-labelled ones included. New ids also need `STORY.aksakal[id]` (`K.variant` copies the base's).

## 4. New locations

### (a) Variants — `K.variant(baseId, newId, opts)`
Copies the def, merges `gen.segments/features`, registers, sets STORY names/aksakal. Options: `name, subtitle, lore, def:{field overrides}, gen:{…}, gradeTiles, gradeBg, gradeSky (static skies only), gradeFg, decorate(L,rng,base)` (runs after base), `postGen(L,rng,genName,base)`.
Grades: `K.grade([{sat},{mul},{add},{bright},{contrast,pivot},{gamma},{hue},{tint,k},{screen,k},{map:[[pos,hex]…],k},{fn}])` → 6-bit LUT. Applied exactly to canvases (`gradeCanvas`, cached `gradedCopy`, `gradeLevelChunks` via `postBake`), approximately (mix toward a fitted color) to per-frame draw layers (`gradedDraw`).

Rules learned:
- **Night = lighting, not LUT**: set dark `ambient/shade/deepShade` and add lights; lanterns then reveal true tile colors. LUT-grade only sky/parallax (not lit).
- Hue-shift looks (drowned) do need `gradeTiles` (gradient map k≈.5).
- Replace or null base `post`/`fogBehind`/`drawForeground`/`ambientFx` — they carry the base time of day (warm rays, sunset grass).
- Base methods use closure caches (`v._sky`) and closure config (`v.gen.base`), not `this` → override `drawSky`, don't change `base/height`.
- Never grade a base canvas in place (some are memoized, e.g. bukhara mist) — `gradeLayers` copies.
- Cave-ify an open level: `K.addCeiling(L, rng, {headroom:[6,11], stal:.2})` in `postGen` (sets `openTop=false`, back walls, recomputes spots/depth; objects stay valid). Then cut back-wall holes for depth.

| variant | shots (`biomes/test/out/`) |
|---|---|
| `tail_night` (night sky+moon `K.nightSky`, graded parallax with lit windows, `K.lantern`, garlands, street lamps, fireflies) | `var_tail_night_B_{0,30,55,80}.png` vs base `var_tail_night_A_*.png` |
| `dream_drowned` (gradient-map tiles+bg, wobble layers, caustics, shafts, bubbles, kelp) | `var_dream_drowned_B_*.png` |
| `ruins_under` (ceiling, cave back tile + frescoes inside structures, deep-cave parallax, torches `PixKit.flameDeco`, crystals, roots) | `var_ruins_under_B_*.png` |
Cost: load 0.3–0.9 s, ~8 ms per tick+render headless.

## 5. Light / glow / particles (world coords; call each frame from draw-phase hooks: `fx`, `draw`, `lights`)
- `G.Light.add(x, y, r, color='#ffcf8a', a=1)` — r = radius px; additive on half-res light map that multiplies the world (can only restore up to texture color).
- `G.Glow.add(x, y, r, color, a=1)` — additive bloom, unlit, on top. Don't call from `update/ambientFx` (tick count per frame varies).
- `deco.light = {r,color,a,flicker,dx,dy}` — auto light per dynamic deco.
- `G.FX.spawn({x,y,vx,vy,life,size,size1,color,color2,alpha,grav,drag,fade,shape:'sq|circle|ring|line|spark|star|rect|custom',w,h,width,rot,vr,glow,glowR,light,lightColor,bounce,update(p),draw(ctx,p,n)})` (max 2600; `glow:true` = unlit glow pass; kill with `p.t=p.life`).
- `FX.burst(x,y,n,{speed,spread,angle,jitter,…spawn opts})`, `FX.dust(x,y,n,s,colors)`, `FX.sparks(x,y,n,dir,{color,color2,speed})`, `FX.debris(x,y,n,dir,colors,{speed})`, `FX.ring(x,y,r0,r1,color,life,opts)`, `FX.flash(color,a)`, `FX.flashLight(x,y,r,life,color)`.
- PixKit (`G.PixKit`): `skyCanvas(stops, steps, sunSpec, pixCb)`, `cumulusPix`, `rangeInto`, `hillsInto`, `cirrusInto`, `flameDeco(x,y,{w,h,lightR,lightC,embers,draw})`, `lampDeco`, `shaftDeco`, `drawSmoke`, `addStatic`, `deepWrap`, `memo`, `hazed`, `cv2pix`, …; `G.Art.glowSprite(r,color,a)`, `Art.drawFlame`, `Art.bandGrad(ctx,x,y,w,h,stops,steps,dither)`.
- BiomeKit: `K.nightSky(o)`, `K.lantern(x,y,o)`, `K.floorRuns(L,min,clear)`, `K.addObjectsAt`, `K.addCeiling`.

## Gotchas
- `ambientFx` particles must be placed relative to `cam` (spawn off-screen otherwise wasted).
- New biome ids: set `music` (else "arena"), `enemyBiome`, `STORY.aksakal[id]`.
- `bakeChunk` makes every chunk non-null (more draw calls); prefer `postBake`.
- Enclosed levels: only `shade`/`deepShade` matter for lighting.
- Variants snapshot the base def at creation: create them after other layers rename/re-lore bases (or pass `name/lore`).
